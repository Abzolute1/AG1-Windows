# Invariants for the migration

These are acceptance properties, derived from execution paths and tests, with explicit target hardening where the current code violates or does not guarantee them. Parentheses name parity rows. No GUI or transport is an authority for task truth.

| ID | Property | Evidence / verification |
|---|---|---|
| I01 | Session/task identity and progress outlive renderer recreation; a window close does not redefine a task or mark it completed. | SDK/RPC/Godot embedding (A02,A73,A78). New frontend-detach/reconnect and explicit-quit tests. Continuing after application exit is a separate host policy, not already-supported daemon behavior. |
| I02 | Every model request uses the current committed branch, current tools/model and context epoch, including requests within an uninterrupted tool loop. | `agent-session.ts:prepareContext`, context-boundary and auto-compaction tests (A14). |
| I03 | No new inference request is admitted while accepted transcript messages remain unpersisted or persistence failure is unresolved. | Event coordinator `wait` barrier (A08). GUI progress notifications are not durable acknowledgments. |
| I04 | Every executed or rejected tool call receives one final outcome in the transcript; native/XML recovery, cancellation and retries cannot silently duplicate mutation. | Loop/extension/XML/file queue tests (A07,A10,A59). Target operation IDs and uncertain-execution recovery. |
| I05 | A context projection may shrink resident data but cannot destroy the only durable copy of required evidence. Tool call/result pairing, recent handoff and original task instructions remain coherent. | Compiler/artifact/compaction tests (A15–A18). Emergency fallback must expose loss/limits explicitly. |
| I06 | A source reference describes the same raw bytes from which the shown evidence was obtained. Stale/missing/invalid/unverified never silently becomes current. | Source revisions/capsules (A33–A36); B03 is a confirmed violation that must be corrected. |
| I07 | Hypotheses, assumptions, decisions, observations and verified results remain distinct. Confidence, model self-report, job exit and compilation do not substitute for requested runtime proof. | Task/episode/runtime/delegation records and completion gate (A22–A30). |
| I08 | Original objective and latest instruction remain separately recoverable. New user steering does not casually reset the long-running task. | `captureTaskInstruction`, task-state tests (A22). |
| I09 | Retrieval selection is deterministic for identical query, source snapshots, revision/Git/access state and budgets. Forbidden/stale results and required evidence quality are independently gated. | source-context/replay fixtures (A33–A37,A76). |
| I10 | Historical artifacts are immutable and integrity checked; mutable leases/catalog/retention metadata does not rewrite evidence. Missing/tampered blobs produce explicit errors. Fork/import preserves the authorized artifact closure. | Artifact/cursor/binary tests (A40–A45); B04 fork regression is required. |
| I11 | Paging and cursors preserve byte semantics across UTF-8, CRLF, restart and transport. Cross-session/store or forged cursor access is rejected. | Artifact store cursor tests (A41,A42). |
| I12 | Context leases and retention are bounded and observable. Expiry/release rules are explicit; no unbounded pinning or unannounced deletion of referenced evidence. | Compiler lease cap, artifact lease/retention tests (A43,A45). |
| I13 | Task, memory, episode and branch mutations have a single authoritative writer/transaction order. React and a migration sidecar never concurrently own the same persistent state. | Session/task locks and source ownership (A22,A38,A46). New import/cutover tests. |
| I14 | A damaged existing persistence file cannot silently become an empty “new” store; migrations preserve original bytes/unknown records and support rollback. | Session quarantine is precedent; B02 requires hardening memory and related files. |
| I15 | Durable acknowledgment has a documented crash guarantee. A machine/process crash cannot make accepted irreversible work appear never attempted. | Target hardening over current heterogeneous writes (A47,D02). Test fsync/transaction boundaries and tool intent/outcome records. |
| I16 | One local single-slot model generation owns its permit until terminal transport/model reconciliation. Queued cancellation cannot leak or steal permits. | Scheduler tests (A57); D06 requires explicit reconciliation when abort is ignored. |
| I17 | Subagent isolation removes transcript cost, not policy obligations. Read-only profiles exclude mutation/recursive delegation by construction; parent policy and partial evidence are retained. | subagent/delegation/checkpoint tests (A70). |
| I18 | User/tool/worker cancellation has defined terminal outcomes; stale retries, compactions and background callbacks cannot mutate a replaced session. | Arbiter/replay/dispose tests (A06,A09). |
| I19 | Workspace identity is explicit in every operation. Process cwd, a visible tab or a URL cannot redirect tools to another project. | cwd/tool factories/native allowlist (A03,A60,A78); D05 target correction. |
| I20 | Approval is checked by core against an operation, project, session epoch and current arguments/revision. Stale/duplicate responses cannot authorize new work. | Existing safety policy and native host broker; target protocol tests. |
| I21 | The process supervisor terminates/reaps only owned children and handles descendants. Explicitly adopted detached services have an ownership/lifetime policy; unrelated PIDs/port listeners are never killed. | jobs/start-token and process tests; D01 correction for model runtime. |
| I22 | Streaming/log producers cannot grow RAM without bound because a renderer pauses. Terminal events/committed state are recoverable; lossy/coalesced progress is labeled and snapshot gaps repaired. | Target hardening over EventStream/RPC (D04). |
| I23 | UI rendering, dialogs, large artifact reads and diagnostics export cannot hold the runtime's mutation/inference locks. Unmounting a panel does not cancel its core task accidentally. | SDK/event seams and Dyad root subscription precedent. New slow UI/core tests. |
| I24 | File mutation preserves intentional edit semantics and mode/encoding behavior; stale preconditions are conflicts, not silent overwrites. | write/edit atomic transaction and diff tests (A62); specialized tool hardening D03. |
| I25 | Provider choice does not silently change requested capabilities or facts. Model/context/projector identity, thinking modes, cache usage and fallback events are explicit. | model registry/capability/runtime tests (A50–A56). |
| I26 | Previewed/generated applications receive no agent credentials, host tool authority or arbitrary filesystem IPC. Native applications and web applications expose different capabilities honestly. | Dyad no-preload preview views and Godot host allowlist; Tauri capability tests. |
| I27 | Product history distinguishes Git commits, session branches, tool transactions and runtime/database snapshots; one cannot be used as proof of another's rollback. | AG1 session tree + Dyad version preview evidence. New dirty-tree/recovery tests. |
| I28 | Default configuration and feature classification come from executable paths, not obsolete comments. Experimental/absent features are not introduced as parity obligations. | CV switches/watchdog defaults/auton/MCP/workflow findings. |
| I29 | Performance comparisons include identical correctness workloads and all relevant processes; no quality loss or missing runtime is credited as speed improvement. | Baseline methodology and replay quality gates. |
| I30 | Copied frontend/code/assets have pinned provenance and approved dependency closure. No Pro implementation enters the product, and notices ship with applicable material. | LICENSE_AUDIT and UI_REUSE_MAP. |

Unresolved behavior choices must become an explicit decision record and test. They may not be hidden in a UI hook, timer, destructor or compatibility adapter.
