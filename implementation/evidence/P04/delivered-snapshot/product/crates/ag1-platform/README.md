# Platform services — P03

Linux native services are implemented. Windows and macOS native filesystem, process-tree and PTY adapters remain unavailable and require real platform fixtures before release. This environment has only the x86_64 Linux target. Network and secret services are explicitly injected fakes; they do not access HTTP endpoints or user credentials.

`WorkspaceService` registers canonical root directory identities and dispatches asynchronous core read/mutation ports through four blocking workers with 64 waiting slots. Workspace IDs include canonical root, device and inode; linked Git worktrees get distinct workspace and Git-directory identities. Operations never change global cwd. Git methods are synchronous: host callers must dispatch them through a bounded executor, never run them on a UI thread.

Linux `openat2` uses `BENEATH`, `NO_SYMLINKS` and `NO_MAGICLINKS`, preserving original AG1's rejection of symlink traversal. Unsupported kernels return an error instead of using a check-then-open fallback. Byte snapshots hash bytes from an open regular file, compare before/after metadata and reopen the path to verify identity. Same-size edits invalidate revisions. Special files cannot block reads through a FIFO/device. Read/write caps are 8 MiB; indexes cap at 1,000 files/16 MiB. Search limit overflow is explicit.

Git file lists include tracked/untracked files and use Git's ignore rules. The non-Git fallback scan skips `.git`, `node_modules`, `target` and `.ag1`; it does not emulate Git ignore syntax. Inotify notifications are invalidation hints; every event, including overflow, requests a full index rebuild. After directory changes, rebuild the bounded watch set along with the index. Manifest summaries retain at most five package scripts, bounded entry paths/package-manager files and 64 language groups; truncation is visible. These are A37 map/index foundations, not a complete context compiler.

Mutations hold a short workspace mutex plus a cooperating-process directory flock. Atomic replacement writes a same-directory exclusive temporary file, preserves ordinary mode bits, fsyncs, rechecks expected revision, renames, and fsyncs the directory. Set-ID/sticky files are refused. A post-publication fsync failure is `DurabilityUnknown`: reconcile instead of reporting success or blindly retrying. `preserve_text` keeps UTF-8 BOM and CRLF style; mixed line endings require explicit byte mutation. Rename requires the original revision and refuses an existing destination. No second journal is introduced.

This is compare-and-swap for cooperating writers, with an external-edit check immediately before publication. Linux has no atomic content-hash-conditional rename against arbitrary non-cooperating editors: an external writer can race the final check/rename. Arbitrary ACL/xattr/ownership migration and filesystem/hardware durability guarantees remain separate work. Symlink swaps before contained opening are rejected; directory capabilities retain the admitted directory identity if another actor moves it after opening.

`GitService` invokes a fixed executable with explicit cwd/environment, disables hooks/fsmonitor/external diff/textconv, caps output and verifies HEAD before/after status/diff. Views are observations, not transactions over externally edited files. `restore_candidate` refuses dirty/conflicted repositories and stale HEAD/file revisions and returns bytes from a pinned commit. It never runs `git reset`, `checkout` or `restore`; subsequent publication must pass CAS. Full tool-level restore/undo policies belong to P09/P11.

`ProcessSupervisor` launches the compiled `ag1-process-host` helper as a direct owned child. The helper has a private Unix socket, executable/start identity and pidfd, establishes its own session, and acts as a Linux child subreaper. It reaps its root and adopted descendants, including descendants holding stdout after parent exit. Cancellation closes the private socket; the helper sends TERM then escalates to KILL via pidfds for its own direct/adopted children. There is no public stop-by-PID or stop-by-port API. Observed services have identity information only. `PortReservation` holds a listener and returns conflict on occupancy. Releasing a reservation before launching a server still requires handling a bind race. Never call the original llama port eviction helper.

The host pins cwd through a directory descriptor before exec, sends argv/env over the private socket, clears ambient environment, and does not log the specification. Input and worker stdout reads cap at 32 KiB. `spawn_protocol` preserves stdout separately from stderr; its kernel pipe applies backpressure and P04 must continuously frame/drain it. Empty reads mean no data currently available; observe exit separately. General logs retain a 64 KiB memory tail and at most 8 MiB on disk per resource, then flag truncation while continuing to drain. Files are created exclusively with mode 0600. Full archival policies/tool outcomes belong to later adapters.

PTY supports bounded byte input/output, dimensions, exit and disconnect. Disconnect cancels the owned tree. Output drains on caller reads: a paused consumer receives kernel backpressure, not unbounded heap growth. Terminal rendering and shell policy are outside this layer.

Cancellation has a maximum configured 1-second grace (100 ms in tests) and a 3-second caller deadline; Git commands have a 10-second deadline. Uninterruptible kernel I/O can exceed these deadlines. Timeout is unresolved ownership, not proof of cleanup. The helper retains its reaping loop during normal timeout escalation; crash/forced-helper-death reconciliation and packaging remain later gates. A fake exit/pipe-EOF state machine covers the Windows hang scenario but does not certify Windows.

The native dependencies added are locked `libc` and `rustix`; `tempfile` is a fixture dependency. All 48 dependency license sets are under `../../licenses/`. The helper is built from this repository, with no downloaded executable. `ag1-platform-fixture` is test-only and must not be packaged. P04 packages only the owned helper. API decisions were checked against [Rustix](https://docs.rs/rustix/1.1.4/rustix/), [Linux subreaper semantics](https://man7.org/linux/man-pages/man2/PR_SET_CHILD_SUBREAPER.2const.html), and [pidfd signalling](https://man7.org/linux/man-pages/man2/pidfd_send_signal.2.html).
