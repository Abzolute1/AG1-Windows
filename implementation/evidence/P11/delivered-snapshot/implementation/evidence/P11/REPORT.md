# P11 project/native runtime acceptance

The P11 completion manifest is the machine authority for this report. It records the executed commands, test counts, current input hashes, immutable delivered snapshot, dependency receipts and retained visual/runtime artifacts. The phase adds real project target adapters to the existing Rust runtime while the normal desktop retains its TypeScript authority.

Delivered APIs and limitations are documented in [PROJECTS.md](../../../../product/crates/ag1-platform/PROJECTS.md). The implementation covers explicit project identity/create/load, workspace files, target/toolchain discovery, install/build/check/run/preview/log/stop/history, durable operation records, grouped child teardown, constrained browser/Tauri preview, real native compiler/runtime diagnostics, Godot v1 host requests/transactions/capture/staging, and guarded file-version recovery. `NativeAdapters.project` composes real target ports with `NativeSession` through P09 policy and durable custody.

The gate runs all four core product crates' test targets because platform process, workspace, Git, session adapters and storage binary-kind validation are affected. It also runs strict Clippy, formatting, desktop fixture builds, the actual interactive WebKit preview, and unchanged pinned Godot/check consumer suites. Empty/skipped selections, incomplete traces, altered tools/runtime material and absent native screenshots cannot pass. `coverage.json` maps P11 requirements to executed success/failure tests; L01–L08 also retain the existing model fixtures and fresh preservation evidence.

`measurements/` separates dependency installation and compiler operations from run readiness, retained-log availability and stop. It contains real Vite interaction and frontend exceptions, real Rust build/run/compiler failure/panic, standalone Tauri frontend/Cargo install/build/dev-group interaction and shutdown, real Tauri/WebKit render/button interaction and native crash, and actual incognito WebKit preview with command denial, constrained navigation and closure. PNGs are rendered captures, not mockups. Browser, target and private display RSS are recorded separately; browser totals include both browser and target group peaks. These finite Linux observations are not per-model, GPU, final renderer latency, whole-desktop or release-performance claims.

Godot protocol/transaction/watchdog/staging tests use a controlled fake native host, with exact private PNG retention and fork authorization tests. They are distinct from the actual Tauri/WebKit/native process proofs. Existing native Godot consumers and their unchanged TypeScript contract suite remain preserved; no claim is made that a stock Godot binary implements the custom host. Native embedding is unavailable. The product reports concrete missing browser/toolchain/platform capabilities. Judge-only vision returns an explicit unavailable response; full UI/client routing is P12. Windows/macOS, packaging, live per-model equivalence and 8h/24h workloads remain their named P14 gates.
