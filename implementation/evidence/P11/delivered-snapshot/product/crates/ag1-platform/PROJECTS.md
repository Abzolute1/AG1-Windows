# Project runtime targets

P11 adds `projects::Runtime`, a host-owned Linux project capability. `load` binds an explicit P03 workspace to a separate private catalog/log workspace, holds one catalog writer, and preserves project/session IDs. Reopened unfinished operations are `RecoveryRequired`; history never adopts a PID. `create` initializes only a requested absent child and removes only that pinned child on failure. Workspace files remain available through the existing P03/P09 APIs.

`discover` reports web, Rust, Tauri, Godot and explicit native targets with manifests, toolchains and actionable capabilities. Tauri discovery includes package.json, Cargo/config/capability JSON/TOML inputs. `command` resolves install/build/check/run commands using admitted Node/npm/Cargo/Godot executables. `checks::detect` additionally recognizes TypeScript script/tsconfig precedence, Go, mypy, C#, configured CMake/Meson, Ninja and C++ Make targets. It never installs a compiler. Run `install` explicitly before checks when a lockfile or dependencies are missing. Packaging needs an explicit platform toolchain; embedding remains unavailable.

`start`, `poll`, `finish`, `stop`, `log` and `history` retain intent, actual argv, source revision, stdout/stderr, terminal state, diagnostics and measurements. Multiple run commands are one owned group; failure or cancellation stops its siblings. Target commands run under P03's private helper and bubblewrap with an empty inherited environment, a writable project, private home/tmp, system runtime files and explicitly admitted read-only toolchain roots. Agent configuration, original user homes, credentials, commands and tuned model paths are absent. Native GUI targets may use `open_private_display` with an installed Xvfb; only its socket and one-time cookie enter the target. Closing a preview does not stop the run. Explicit stop/quit drains owned resources.

HTTP readiness requires an exact expected body and a listener held by a descendant of the current owned process. Foreign occupancy rejects launch; port observations never authorize stopping anything. A live native PID stays `Starting` until actual runtime evidence exists. Compiler success is reported independently from runtime and visual proof. Process output quotas produce a visible failure with retained evidence, never a false successful truncation. `observed_pids` provides observations solely for diagnostics/leak tests.

`CheckPort` and `VisualPort` implement `target_tools::Port` for P09 `Service`. `ProjectPort` is also admitted through `NativeAdapters.project`, so `NativeToolRunner` wraps execution with the existing policy, approval, acknowledged intent/result, recovery and verification custody. Preparation performs no launch or navigation; revalidation binds source/configuration/toolchain inputs. Check `passed` additionally requires unchanged source revision at completion. Selected files are containment-checked and appended for TypeScript, preserving the reference behavior; other compilers retain whole-project scope.

`preview::Grant` binds one live operation, session and exact loopback origin. `Browser` is an optional separately supervised Playwright/Chromium process with bounded requests/results, denied external URLs/popups/downloads/service workers, isolated browser context, runtime console/error capture and screenshots. It receives no model endpoint. `VisualPort` requires the caller's actual model/projector vision capability, retains screenshots in P05's authorized branch artifact store, and returns evidence for caller assessment. It does not invent a visual verdict or silently request a judge model. Judge-only attachment is unavailable until a separately admitted P06 scheduler binding exists.

The desktop host-only `ag1_desktop::project_preview::ProjectPreview` opens an incognito Tauri WebKit window with constrained navigation and denied new windows. Its label receives no AG1 capability and existing commands reject any window except `main`. `focus` revalidates the live run; `close` invalidates the presentation grant. P12 supplies client/UI actions; the normal P04 desktop still executes the TypeScript worker.

`godot::{decode,encode,handshake,Broker}` keeps the pinned v1 schema hash, nonce, envelope/size limits, explicit host method allowlist, Build-mode mutation fence, transaction/operation IDs and parent EOF/deadline watchdog. The existing native Godot host remains the transaction/playtest authority; there is no hidden TypeScript AgentSession. Requests are serialized below the original 256-pending limit. Uncertain responses close the broker and require inspection instead of retry. `capture` verifies a private PNG's path/hash/size/dimensions and vision capability; `preview::retain` uses the existing binary artifact/branch/fork retention schema. `verify_stage` and `copy_stage` preserve admitted backend manifests, bytes, executable modes and adjacent symlinks in a new destination without discovery, download, rebuild or tuning. Escaping links are rejected as a containment correction.

`GitService::{history,preview_version}` returns bounded history and a clean, expected-HEAD/file-bound candidate. `Runtime::restore_version` records the before-image and intent privately before `GitService::apply_version` rechecks HEAD/dirty/conflict and file CAS. It restores one reviewed file, leaves HEAD and session/native/database state alone, and records rejected or uncertain recovery. Chat-tree navigation never invokes it.
