### 🏆 Universal Meta Weapons (Worth Any Class Bonus)

These weapons are so strong that players often sacrifice their class proficiency for them:

- **M4A1 Carbine** — The most universal weapon in the game. Works well for ALL classes, all playstyles.
- **NVO-228E** — Beta-dominating assault rifle, viable cross-class.
- **SGX SMG** — Close-quarters king, worth it on any class when CQB is expected.

---

### ⚠️ Important Game Mechanics to Note

1. **Open Weapon System** — Any class can equip any weapon, but you lose your class proficiency bonus for off-class weapons.
2. **Headshot multiplier is only 1.35×** (vs 2.0× in older BF games) — Consistent body-shot TTK matters more than headshot hunting.
3. **Support's LMG mobility** is the most unique class perk in the game — removing sprint penalties completely changes how LMGs function.
4. **Map matters** — The best weapon shifts based on map layout. Large open maps favor ARs/LMGs/snipers; building-heavy maps favor SMGs/shotguns.
