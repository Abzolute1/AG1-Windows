# Archived implementation records

These are historical checkpoints, not a work queue. Start with [current implementation status](../../README.md) and [remaining tasks](../../../tasks/README.md). Read an individual record for its implementation details, failures and evidence.

Original bytes of all 76 former top-level Markdown files, plus changed incoming-link documents, are in [original-documents.tar.gz](original-documents.tar.gz). The [manifest](manifest.json) maps every old path and hash to its readable archived copy. Existing evidence and receipts retain their original content and paths; use that map when following a relocated historical reference. Two [compatibility originals](compatibility/) preserve P12/P13 inputs used by release tooling.
