## Pull/checkout publication foundation (not yet connected)

The next continuation adds `workspace_git.rs`, a native-only working-entry publication primitive. `GitEntry` represents exact blob/link bytes and Git mode; `GitSnapshot` adds full native inode/revision identity. It snapshots final symlinks without following their targets (including non-UTF-8 target bytes), rejects symlinked ancestors and special entries, and publishes regular files/executable files/links/deletions with NOREPLACE. Displaced originals are retained at native sibling recovery names or in a pinned root recovery directory, allowing later directory-to-file transitions without trapping backups inside the directory being replaced.
